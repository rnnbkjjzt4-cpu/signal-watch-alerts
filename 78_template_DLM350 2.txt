### How It Works
1. Database:
   - Customer: Stores customer name and phone, linked to Job.
   - CompletedJob: Archives finished jobs with all details (address, employee, customer, durations, etc.).
2. UI:
   - Add Job: Now includes a customer dropdown.
   - Index: Adds a yellow "Finish Job" button per job card and a "View Completed Jobs" link.
   - Completed Jobs: A separate page lists archived jobs in cards.
3. Logic:
   - Clicking "Finish Job" triggers a confirmation popup, then moves the job to CompletedJob and deletes it from Job.
   - Timers and other data are preserved as strings in the archive.

### Running It Locally
1. Save app.py in your project folder.
2. Create a templates folder with index.html, add_job.html, and completed_jobs.html.
3. Install dependencies: pip install flask flask-sqlalchemy.
4. Run: python app.py.
5. Visit http://127.0.0.1:5000.

### Deployment Notes
If deploying (e.g., on Render, as discussed earlier):
- Update requirements.txt with flask-sqlalchemy.
- Ensure the instance folder is created for SQLite, or switch to PostgreSQL for persistence.
- PDFs in uploads won’t persist unless you use cloud storage (e.g., S3).
